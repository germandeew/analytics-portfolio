# Офлайн-CRM для кальянной (пет-проект)

**2026 · собственный проект · Python, локальный веб-интерфейс, Windows-установщик**

## Задача

Заведению нужна учётная система на одном Windows-ноутбуке без интернета: смены, зал, брони,
склад, заказы по станциям, оплаты и бонусы. Облачные CRM не подходят из-за связи и стоимости.

## Что сделал

- Описал процессы заведения и роли (кальянщик, бармен, повар, управляющий, админ, владелец);
  один человек может совмещать несколько ролей.
- Сделал зал с планом и карточками столов, брони с депозитом без двойного бронирования, техкарты
  и списание со склада, станции кухни, бара и кальянной с отметками времени, разделение счёта по
  гостям, бонусы и отчёты для владельца.
- Сделал распознавание чеков из магазина без интернета: строки сверяются арифметикой и с итогом
  из QR-кода, и на склад ничего не попадает без подтверждения человеком.
- 200+ автотестов, сборка Windows-установщика в CI, чек-лист безопасности для каждой функции.

## Статус

Рабочий прототип. Репозиторий закрытый, код покажу по запросу.
